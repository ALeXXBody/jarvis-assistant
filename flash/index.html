J.A.R.V.I.S. satellite — install from the browser

Flash the GUITION JC8012P4A1C 10.1″ panel (ESP32-P4) straight from this page over USB — no toolchain, no PlatformIO, no esptool install. Powered by ESP Web Tools (the same installer technology ESPHome uses).

→ Firmware already on the panel? Watch its live serial log in the browser (same USB cable, zero-install).

Checking which firmware this page will install…

Browser support: Chrome, Edge or Opera on a desktop (Web Serial). Firefox and Safari cannot access USB serial devices. Localhost over plain HTTP is fine.

1 · Plug in

  1. Connect the panel to this computer with a USB-C data cable (not charge-only).
  2. Power it from a ≥ 2 A 5 V supply — a weak supply can brown out during the erase/flash — or keep it on its own PSU and plug the cable into the other USB-C port.

2 · Install

Click Connect, pick the panel’s serial port in the browser’s device chooser, then accept the browser prompt. The install erases the flash (including whatever demo the factory left, and settings) and writes the merged JARVIS image at offset 0.

This browser can’t install on ESP devices — use Chrome, Edge or Opera on a desktop, or the manual flasher below. This page must be served over HTTPS or from localhost — see the manual flasher below.

First flash takes a few minutes (16 MB erase + ~1 MB at −b 115200). Keep the page tab focused.

2b · Update a panel that already runs JARVIS (keeps Wi-Fi + brain URL)

Use this button to move an already-flashed panel to the new firmware without erasing settings. It writes only the bootloader, the partition table, the OTA slot selector and the application — never the settings (NVS) region — so the Wi-Fi credentials and brain URL you entered on the panel survive the update.

This browser can’t install on ESP devices — use Chrome, Edge or Opera on a desktop. This page must be served over HTTPS or from localhost.

Connect, pick the panel’s port and confirm; the panel reboots into the new firmware with its settings intact. Use the Install button above only for a first-time flash or when you want to wipe the board.

3 · First boot

The panel boots into JARVIS and starts a background update check against its configured release URL. To configure your brain URL for the first boot — see the README’s Configuration section — or watch pio device monitor for the console keys.

Manual fallback (no custom page): Espressif’s ESP Tool

If the one-click button misbehaves, any address-based web flasher works the same way. With Espressif’s official ESP Tool (esptool-js) or the equivalent esp.huhn.me:

  1. Download firmware.factory.bin from this repository’s latest release.
  2. Open the ESP Tool page → Connect → pick the panel’s port (P4 exposes USB-Serial-JTAG; on Linux that’s /dev/ttyACM0).
  3. Baud 460800 or 921600.
  4. Add firmware.factory.bin with Flash address 0x0.
  5. Leave all three flash settings (“mode / frequency / size”) on “keep” — the merged image already carries the correct qio / 80 MHz / 16 MB settings in its header, and browser flashers don’t patch them after the fact.
  6. Press Program, then power-cycle the panel when done.

Troubleshooting

  • No port in the chooser — hold BOOT, tap RESET/PWR, release BOOT to force ROM download mode, then connect again.
  • “Failed to claim interface” — close any open serial monitor (pio device monitor locks the port) or, on Linux, add yourself to the dialout group and re-login.
  • Flash dies mid-way — power brownout; raise to a ≥ 2 A supply before retrying.
